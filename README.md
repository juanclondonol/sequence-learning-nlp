# NLP Sequence Tasks

This repository contains practical exercises developed for the Natural Language Processing (NLP) course. It covers three foundational architectures and tasks in modern NLP, implemented using Python and Deep Learning frameworks.

## Repository Structure

Each folder contains the notebooks and implementation details for its respective task:

*   **[Sequence Classification](./Sequence-classification/)**  
    Text classification tasks such as sentiment analysis, topic detection, or spam filtering.
    
*   **[Sequence Labeling](./Sequence-labeling/)**  
    Token-level classification tasks, including Named Entity Recognition (NER) and Part-of-Speech (POS) tagging.
    
*   **[Sequence to Sequence (Seq2Seq)](./Sequence-to-sequence/)**  
    Encoder-decoder architectures used for generative tasks like machine translation, text summarization, or question answering.
